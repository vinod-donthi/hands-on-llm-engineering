## Style guide

- Light background (`#fafafa`), dark text (`#1a1a1a`)
- Accent blue `#2563eb` (model / tokenizer), accent orange `#ea580c` (cost / limits)
- Max width ~720px in SVG `viewBox`; figures should read on mobile GitHub preview
- Alt text: one sentence describing what to notice
- **SVG must be valid XML:** use `&quot;` for quotes, `&amp;` for ampersands, ASCII punctuation only (no smart quotes or special Unicode arrows)

**Full authoring rules:** [.cursor/rules/learning-svg-assets.mdc](../../.cursor/rules/learning-svg-assets.mdc) — arrowhead size, box gaps, no text/line overlap, `xmllint`, preview check.

### Quick layout rules

| Rule | Value |
|------|--------|
| Arrowheads | 6×6, `markerUnits="userSpaceOnUse"`, 1.5px stroke |
| Gap between boxes | ≥20–24px (room for arrows) |
| Lines / arcs | Never through box interiors; arcs above/below token rows |
| Labels | Within 6–12px of the element; leader line on curves; not at Bézier control points |
| Chart bars | Bottom anchored on axis line |
| Before commit | `xmllint --noout` + markdown preview visual check |
